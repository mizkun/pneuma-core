# Pneuma 面白さエンジン設計原則

作成日: 2026-05-28
作成者: PO（きょうへい）+ Iris の議論より
位置づけ: Pneuma の「面白さ」をどう生むかの設計指針。思惑エンジン実装の土台。

## 背景

Phase 0 C2 の試聴ゲートで、リアル Claude で 3 体会話を実機検証した結果：
- 素の雑談（夏祭り楽しみ）→ 平坦（感情高止まり、退屈）
- 対立コンテクスト（文化祭の出し物）→ ちょっと面白い（意志のぶつかり合い）

PO 判定「正直面白くはないが日常系として成立。**落ちがない**」。この「落ちがない」を起点に、面白さの本質を議論した。

## 面白さの定義 — 共感と発見のバランス

**面白さ = 共感（解釈一致）と発見の共存。**

| 軸 | 中身 | Pneuma での担保 |
|---|---|---|
| **共感（解釈一致）** | 「このキャラならこう反応するよね」という予測の的中 | 🟢 既存の強み。Big Five（性格の一貫性）× 記憶（過去と矛盾しない） |
| **発見** | 「こんな展開も！意外な一面！伏線回収！」予測の裏切り | 🔴 課題。さっきの会話で欠けてた |

- 推しなら共感だけで保つが、通常は発見が必要
- 発見はうんちくである必要はない。意外な展開・伏線回収・面白さ・怖さなど

## 発見の二層構造（C を採用）

| 層 | 発見の種類 | 必要なもの | 効く相手 |
|---|---|---|---|
| **長期（時間軸）** | 記憶の伏線回収、関係性の変化 | 長期記憶（Pneuma の核） | リピーター |
| **セッション内** | 思惑の衝突、speech/thought ギャップ | 思惑エンジン | 初見も |

- North Star = 「勝手に発見が起きるのを期待する」プロジェクト → 長期は絶対に賭ける
- ただし長期だけだと初見がつまらない → セッション内の発見も要る（C）
- 初見は共感で掴み、リピーターに発見を提供する二層構造（きらら系と同じ）

## 台本化しない発見 — 「展開」を書かず「火種 + 着火条件」を仕込む

| | 台本 | 創発（Pneuma） |
|---|---|---|
| 仕込むもの | 展開そのもの（turn 8 で告白する） | 火種 + 着火しやすさだけ |
| 発見の質 | 毎回同じ | 予測不能（観るたび違う） |

例：「カフェ推しのなでしこが実は料理下手」という火種 → 推すほど墓穴、感情が高ぶると口が滑る（性格）→ いつバレるか・バレないかは自律。展開は決めない。

## 視聴者非意識 × 面白い の両立 — 思惑エンジン

**ラジオとの決定的な差：Pneuma のキャラは視聴者を意識しない（下位存在）。**

| | ラジオ | Pneuma |
|---|---|---|
| キャラの意識 | 視聴者を楽しませよう（メタ） | 視聴者を知らない |
| 会話の駆動力 | サービス精神 | **キャラ自身の思惑** |
| 観察価値 | プロの話芸 | 演技じゃないガチな思惑のぶつかり合い |

ラジオの「面白くしよう」を入れると視聴者を意識して North Star が崩れる。代わりに **各キャラの「思惑（短期ゴール）」** を会話の駆動力にする。

### 思惑の区別

| | 性質 | 可否 |
|---|---|---|
| ❌「視聴者を面白がらせよう」 | メタ意識 | NG |
| ⭕「自分の思惑を達成したい」 | 内発的 | OK |
| ⭕「場を盛り上げたい（自分が楽しいから）」 | 性格由来（外向キャラ） | OK |

### 思惑エンジンの仕組み（採用案 A：長期欲求から創発）

```
キャラの長期欲求（values / desires / goals）
  + セッションの状況（コンテクスト注入）
  → 短期ゴール（思惑）が創発  ← 台本じゃない
  → 全員の思惑がぶつかる
  → 会話に推進力・対立・発見が生まれる
```

例：
- 千明「認められたい・リーダーでありたい」+ 文化祭 → 「自分の企画を通す」
- なでしこ「人を喜ばせたい・褒められたい」+ 文化祭 → 「カフェで料理を褒められたい」
- あおい「平穏でいたい・みんな仲良く」+ 文化祭 → 「対立を収めたい」

思惑には表裏を作れる：
- 千明 表「お化け屋敷が盛り上がる！」/ 裏「本当はなでしこに負けたくないだけ」
- → speech/thought ギャップ = 視聴者だけが知る本音 = 観察の快楽 = North Star そのもの

## 設計原則まとめ

1. 面白さ = 共感 + 発見のバランス
2. 共感 = 性格 × 記憶の一貫性（既存の強み）
3. 発見 = 時間軸（長期）+ 思惑の衝突（セッション内）の二層
4. 台本化しない = 展開を書かず「思惑（火種）+ 着火条件」を仕込む
5. 思惑 = キャラの長期欲求から創発（視聴者非意識のまま会話を駆動）
6. speech/thought ギャップ = 視聴者だけが知る本音（観察の快楽）

## ターン尺の知見

- リアル Claude で約 15-20 秒/ターン（思考 + 発言 + 感情評価で複数コール）
- 15 分配信 = 約 45-60 ターン（TTS つきで 35-40 ターン）、各キャラ 15-20 発話
- → 1 セッションに「思惑に向かって進行 → 達成 or 決裂」のアーク（起承転結 + オチ）が収まる尺

## 実装方針（思惑エンジン）

既存資産：`models/values.py`, `models/goals.py`, `contracts/goal-tree.yaml`（長期欲求の素地は既にある）。
overnight の multi_agent 実装はこれらを思惑として活用していなかった。

実装すべき：
1. キャラに長期欲求（desires/motivations）を明示的に持たせる（values/goals の活用 or 拡張）
2. 長期欲求 + 状況 → 短期ゴール（思惑）の生成ロジック
3. 思惑をプロンプトに反映して会話を駆動
4. speech/thought ギャップの強化（表の思惑 vs 裏の本音を分離生成）
5. 思惑を観測可能にする（ダッシュボード/ログに「現在の思惑」「本音」を表示）
6. 思惑ありで再試聴 → 面白さ（特に発見）が上がるか検証

# 第 2 ラウンド議論（2026-05-28〜29）— 謎と解明・クセ・台本化の境界

思惑エンジン（#20）を実装してリアル Claude で 3 回検証した後の、より深い議論。

## 実機検証の発見（#20 思惑エンジン後）

| セッション | お題 | 結果 |
|---|---|---|
| 文化祭（対立） | 出し物をカフェ vs お化け屋敷で今日中に決める | 思惑が逆方向でぶつかり推進力◎。本音(thought)で発見◎。**但し落ちない**。全員 sad_lite に収束 |
| フグ（哲学問い） | フグ 2 回目に食べた人の気持ち | 問いの引き◎。**但し一問一答で収束、落ちない**。全員 happy に収束。全員「ロマンあるね」で合意（クセがない） |

**共通する 3 欠陥：(1) 謎が連鎖しない（一問一答で閉じる）、(2) 答えが割れたまま残らない、(3) 感情が全員同方向に高止まり（温度差なし）。**

## 謎と解明の理論（面白さの根本）

**面白さ = 「謎 → 解明」の繰り返し。解明の質 = 共感（理解できる）と発見（なるほど）の共存。**

- **謎度はコンテクスト依存**：ハイコンテクスト（愛着）があれば、どうでもいい話でも謎度が高い（友達の昼飯は気になる、知らない人のは気にならない）。ローコンテクストでも問い自体の引きで謎度を上げられる（密室殺人）。
- **愛着 = ハイコンテクスト性**。愛着は結果論で直接作れないが、「謎度を上げるコンテクスト」と再定義すると設計できる。
- **提供すべきもの**：ローコンテクスト × 高頻度の小謎（誰でもすぐ気になる）＋ ハイコンテクスト × 低頻度の大謎（長期の引っ張り）。
- ラジオのお便り = ローコンテクストな小謎の供給装置。「この問いにパーソナリティがどう反応するか」が謎。
  → Pneuma では **コンテクスト注入を「状況」から「お便り（問い）」へ格上げ**する。

### 謎の種類（スペクトラム）

| 種類 | 引き | キャラ性が出るか | 適性 |
|---|---|---|---|
| 正解のある謎（なぞなぞ） | 中 | ✗ 誰でも同じ答え | ❌ 形式の必然性が消える |
| 正解のない問い（哲学・想像） | 高 | ◎ 価値観・想像力が出る | ✅ スイートスポット |
| メタ謎（AI はどう議論するか） | 高 | ◎ | ✅ 長期の引き・North Star |
| キャラの謎（新キャラ・出自・因縁） | 高 | ◎ | ✅ ハイコンテクストの大謎 |

ローコンテクストすぎる謎（なぞなぞ）は「このキャラ・この形式である必要」を消す。正解のない問いだけが、問いの引き × キャラ個性を両立する。

## 発見を生む具体メカニズム

### 水平思考的飛躍

「フグもXXも一緒だよね」= 抽象構造を抜き出して別の具体例に再着地する飛躍。
- 発見 = 繋がるとは思わなかった意外性
- 共感 = 言われてみれば確かに（生活実感への着地）
- 肝は**距離**：離れすぎ＝意味不明、近すぎ＝当たり前。**絶妙な距離の飛躍**が「なるほど！」を生む。

フグ実験は垂直に深掘りしただけで水平に飛ばなかった（情報伝達 → 運 → 餓死 → 技術）。「展開」= 垂直（深掘り）＋ 水平（飛躍）の両方があって豊かになる。

### ロジカルじゃないクセ（最重要）

**LLM は RLHF で「賢く・無難・balanced」に調教されている。放っておくと優等生になる。** フグ実験で全員が賢く無難に答えたのはこれ。

面白さはロジカルさの外にある。**お題を自分のクセに引き寄せる**のが大喜利的面白さ：
- 千明（何でも勝負に変換）「1 回目の奴に勝ちたかったんだろ」
- なでしこ（全部食い意地）「お腹空いてたんだよ絶対」
- あおい（妙に達観）「喉元過ぎれば熱さ忘れる、やね」

短く・ロジカルじゃない・でも「このキャラならこう言う（共感）× その角度か（発見）」。クセ・偏見・思い込み・ボケは意図的に強く promote しないと出ない。

### テンポ

サクサク進む。大喜利の呼吸。発話を短く（フグ実験は長く丁寧で説明的すぎた）。「間（タメ・沈黙）」も大事だが**演出レイヤー（TTS/画面）の領域で、自律会話では狙えない → 後回し**。

## 台本化の境界（判断基準）

| 分類 | 定義 | 台本か |
|---|---|---|
| ❌ 台本 | 出力（セリフ・展開・結末）を事前に決める | 台本 |
| ⭕ 創発 | 入力（性格・クセ・欲求・お題・締切）を設計、出力は自律 | 台本でない |
| ⭕ 編集 | 生成済み素材から事後的に選ぶ・切り出す | 台本でない |
| ⭕ メカニカル | 内容に関与しない形式制約（文字数・ターン上限） | 台本でない |

**線引き = 「出力を決めたら台本／入力を設計するなら創発」。**

### 要素ごとの仕分け

| 要素 | 台本になる実装（避ける） | 創発/他で守る実装（採用） | 分類 |
|---|---|---|---|
| お題（謎） | シナリオを書く | 状況・締切だけ与え展開は委ねる | 創発 |
| クセ | セリフを書く | 思考傾向を character.yaml に与え適用は自律 | 創発 |
| 水平思考 | アナロジーを指定 | 「連想して飛ばす」傾向を促す、中身は自律 | 創発 |
| 思惑 | ゴールと手順を書く | 長期欲求から創発（#20 済） | 創発 |
| テンポ | ターン長を台本指定 | max_tokens + 「短く」指示 | メカニカル |
| 感情の起伏 | 「ここで悲しむ」 | 感情ダイナミクス調整（減衰・温度差） | 創発 |
| 🔴 オチ | 結末を書く | 二段構え（下記） | — |
| 🔴 伏線・大謎 | turn3 で振って turn10 で回収 | 長期記憶の自律的想起 | 創発（長期） |

**台本リスクが高いのは「オチ」と「伏線」の 2 つだけ。他は創発/メカニカルで守れる。**

### オチ → 二段構え（生成は台本化しない）

- **ライブのオチ**：締切・決定の外圧でゆるく収束（「今日中に決めなきゃ」）。完璧でなくていい。創発寄り。
- **編集のオチ**：後から面白い区間を切り出す（切り抜き = M2）。編集。**面白さの完成度はここで担保**。
- ラジオが生放送 + 切り抜きなのと同じ。**生成自体はオチを書かない**。

### 伏線・大謎 → 長期記憶の自律想起

記憶に残った何かが、後で関連状況でふと想起される。いつ・そもそも回収されるかは自律 → 台本でない。狙った伏線にはならない（偶発的）が、本物の "発見" になる。Pneuma の記憶システムがこれを可能にする。

## 実装ロードマップ（段階・全部台本化しない）

| 段階 | 内容 | 分類 | 状態 |
|---|---|---|---|
| 0 | 思惑エンジン + speech/thought | 創発 | ✅ #20 実装済 |
| **1（直近）** | クセ + テンポ | 創発 + メカニカル | 次 |
| 2 | 水平思考的飛躍 | 創発 | |
| 3 | 感情の温度差・収束（高止まり解消） | 創発 | |
| 4 | 構造的オチ（お題に締切/決定を仕込む） | 創発 | |
| 5 | 編集オチ（切り抜き） | 編集 | M2 |
| 6 | 大謎・伏線（長期記憶活用） | 創発（長期） | 長期 |

**一度に全部入れない。クセ+テンポ → 検証 → 次、と刻む（何が効いたか分かるように）。**

## 価値観（Values）の活用メモ

フグ実験で全員「ロマンあるね」に収束したのは、3 キャラの Values（Schwartz）が似ていて割れなかったから。哲学的・価値観的な問いは Big Five（性格）より Values が反応を分ける。self_transcendence（他者のため）と self_enhancement（自己実現）が対立する 3 人なら、同じ問いへの答えが本質的に割れ、割れたまま残る = 引きになる。段階 1 以降でキャラの Values 対立を設計する。
